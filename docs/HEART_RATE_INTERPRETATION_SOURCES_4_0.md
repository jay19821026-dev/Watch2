# Heart-rate result wording / 心率結果文字依據

The phone result page shows plain-language context only for a typed Wear Health Services heart-rate measurement with a trusted, current timestamp. A PPG research pulse estimate is not substituted for this typed measurement. The activity/rest state is not known, so the page phrases the adult **resting** 60–100 bpm reference conditionally, does not label a single watch value as a rhythm diagnosis, and asks the user to remeasure after resting when a result is unexpectedly high. The separate ECG result still requires its own waveform assessment.

手機結果頁只對有可信時間戳的 Wear Health Services 心率給出一般文字說明；不以未校準的 PPG 估算值替代。量測時是否靜息未知，因此成人**靜息** 60–100 bpm 只作條件式比較；較快或較慢時說明可能影響因素、重測及何時就醫，不把單次 bpm 判成心律疾病。

Sources / 資料來源：

- [American Heart Association, All About Heart Rate](https://www.heart.org/en/health-topics/high-blood-pressure/the-facts-about-high-blood-pressure/all-about-heart-rate-pulse): adult resting reference, exercise/emotion/medication effects, and when to contact a professional.
- [American Heart Association, Target Heart Rates](https://www.heart.org/en/healthy-living/exercise-and-physical-activity/fitness-basics/target-heart-rates/): adult resting 60–100 bpm and activity dependence.
- [NHS, Heart palpitations](https://www.nhs.uk/symptoms/heart-palpitations/): seek medical help for recurrent palpitations and urgent care with chest pain, shortness of breath or fainting.

These sources support the **wording of health context**, not AILISA device calibration, ECG classification, AF sensitivity/specificity or FDA clearance. / 以上來源只支持一般健康說明文字，不代表 AILISA 手錶校準、ECG 分類準確率或 FDA 認證。
