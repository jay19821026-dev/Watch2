## 安裝 / Install

1. Download both files, verify SHA-256, and keep the phone and watch paired through Wear OS / Google Play services. / 下載兩支 APK、核對 SHA-256，並確認手機和手錶已配對。
2. Install the Mobile APK on an Android phone (minimum API 28). / 在 Android 手機安裝 Mobile APK（最低 API 28）。
3. Install the Wear APK on the Xiaomi Watch 2 Pro or compatible Wear OS watch (minimum API 30), using a watch-side installer or ADB. / 在手錶安裝 Wear APK（最低 API 30），可使用手錶側載工具或 ADB。
4. On each device, open the app and grant only the permissions needed for the feature being tested. Health Connect and OEM Mi Fitness permissions are separate. / 分別開啟 App 並按測試功能授權；Health Connect 與原廠 Mi Fitness 的授權各自獨立。

ADB users may install the phone APK with `adb install -r <mobile-apk>` while the phone is selected, then select the watch and run `adb install -r <wear-apk>`. Check the selected device first with `adb devices -l`. The repository's [`install-apks.ps1`](../install-apks.ps1) is an alternative that builds and checks the current version before installing. / 使用 ADB 前先確認選中的裝置；`-r` 是覆蓋更新，不能越過簽章不符。

## 4.0 測試重點 / What to test

- Phone: Open **血氧** detail and check the Health Connect source and manual, active, automatic, or unknown recording-method filters. The label comes from source metadata and does not certify calibration. / 手機血氧詳細頁檢查來源與量測方式篩選；量測方式不是校準證明。
- Test 21 Health Connect source audit / 資料來源核對：On the phone open **裝置 → 同步明細 → 核對 Mi Fitness／Health Connect 資料來源**. Before granting permissions, each type must say 未授權. After granting selected read permissions through **裝置 → 管理 Health Connect 權限**, refresh and compare source package, record count, series sample count, and latest sample time with Health Connect's own data list. The ten inspected types include exercise sessions, elevation, speed and step cadence; speed requires a separate read grant. No numeric health value or exercise route is shown in this audit. / 未授權時應明確顯示未授權；授權後再核對來源、紀錄筆數、樣本數與最新樣本時間。不能因 Mi Fitness APK 有寫入程式就推定已同步。
- Test 22 workout samples / 運動樣本：After a recorded GPS route and explicit Health Connect grants, open **運動路線分析**. GPS estimated average speed and Health Connect speed/cadence sample means appear separately, with source packages kept separate. No samples, denied permission, read errors and the record bound have different messages. A time match does not prove the samples came from this watch. The paired phone has not yet granted these read permissions, so real OEM-exported values remain unverified. / 有路線且授權後，核對 GPS 推算速度及同時段 Health Connect 速度、步頻樣本；按來源套件分開，不將時間重疊當作手錶來源證明。
- Test 23 step-source fallback / 步數來源備援：On **摘要**, Health Connect's deduplicated `COUNT_TOTAL` remains preferred. If it is unavailable, the recent-day raw-record fallback now sums only nonoverlapping intervals within each source. With multiple sources it shows the highest individual source value, explicitly labelled **not the deduplicated total**; overlapping intervals within a source are rejected. / 平台總步數優先；備援不直接合計手機與手錶的重疊紀錄，並清楚標示來源最高值不等於去重總數。
- Test 24 active-calorie fallback / 活動熱量備援：On **健康**, `ACTIVE_CALORIES_TOTAL` remains preferred. If unavailable, the card may show the latest day's highest source subtotal from readable, nonoverlapping intervals, with date and an explicit non-deduplicated label. A partial day's records are not a complete daily energy total. / 平台彙總優先；備援只顯示同日可讀紀錄中各來源的最高小計，不冒充完整或去重日總量。
- Test 25 heart-rate sample trend / 心率樣本趨勢：On **健康**, two Health Connect records from the same source can now contribute distinct in-range sample timestamps to the 24-hour trend even if their enclosing record intervals overlap. Duplicate sample timestamps and multiple source packages still do not merge. / 同來源紀錄區間重疊但樣本時間不同時，趨勢可顯示有效樣本；重複時間及多來源仍不合併。
- Test 20 Wear home / 手錶首頁：The AILISA header, two-line heart-rate prompt and full measurement button should be visible without overlap on a 466 × 466 round display. The [real test 20 Wear screenshot](images/play-wear-home-test20-466x466.png) documents the charging, non-measurement state. / 已核對名稱、圓形心率提示與完整按鈕；截圖不是量測結果。
- Watch: Open **查看原廠功能入口** and tap one feature at a time. The app requests an exported Xiaomi page; the OEM app decides whether it can open and whether the feature is active. / 手錶逐一點擊原廠功能入口，由原廠畫面顯示實際可用狀態。
- ECG: In **ECG RESEARCH**, end this app's raw capture before tapping **開啟原廠 ECG 頁面**. This button only opens the OEM page; it does not query or change its activation state. If Mi Fitness offers an ECG card for this paired watch, use its official phone flow. / ECG 原始擷取和原廠頁面分開測；按鈕只開原廠頁，不會查詢或修改啟用狀態。
- ECG preview: the candidate line should break after an event timestamp gap longer than one second or a missing/nonincreasing timestamp. This tests display continuity only; it does not validate the 25-second OEM record rule, ECG units, or rhythm. / 原始事件時間中斷時，研究預覽應斷線，不代表正式 ECG 紀錄有效。
- ECG warm-up: the first 20 callbacks of this app's capture remain in raw storage but are omitted from the drawn candidate preview, following the observed OEM watch path. The candidate line can appear only after later marked, on-body packets. / 前 20 個回呼只不畫線，原始資料仍保存；第 21 個以後仍須通過標記與配戴檢查。
- Sleep: On the phone, open **睡眠** with Health Connect sleep permission. Complete, known and non-overlapping stages subtract awake time and label the main number as sleep time. Missing, partial or overlapping stages leave a deduplicated session span labelled as possibly including wake. Each recent row identifies its source app. / 手機睡眠頁有完整可靠分期才扣除清醒；否則顯示可能包含清醒的時段，並列出資料來源。
- Stress / 壓力: With the watch properly worn, run the optical HRV research page and check whether a research stress score appears only after a valid optical signal and at least five RR intervals. Repeat off-wrist; a raw event may remain, but the stress score should be absent. This is **our heuristic**, not Xiaomi's `20486` result or a blood-pressure reading. / 戴錶與離腕各測一次；離腕可保留原始資料，但不應顯示本專案研究壓力分數。不得把它當成小米原廠壓力或血壓。
- Test 16 stress comparison / 壓力對照：On the watch HRV research page, tap **查看原廠壓力量測**. The app stops its own capture before requesting the exported Xiaomi Health stress screen. Compare only whether the OEM screen opens and shows its own availability; its typed service result is not imported into this app. / 研究頁新增原廠壓力入口；切換前中止本 App 擷取。能開啟頁面不等於原廠量測成功。
- BioZ / 體成分原始擷取: In the watch BioZ research page, compare worn and off-wrist runs. A recent on-body event plus at least 40 raw events is needed for a raw-capture completion label. This does not verify finger contact with the watch buttons, physical ohms or body-fat percentage. The phone-triggered BioZ path uses the same gate. / 戴錶和離腕各測一次；本專案只確認原始事件及近期佩戴狀態，不產生原廠體成分結果。
- Guided breathing / 引導式呼吸練習: On the watch home, tap **原廠呼吸練習 · 非呼吸率**. The exported Xiaomi Health page should open, if available. Its 1–5-minute exercise and optional start/end heart rate belong to the OEM app. Do not interpret this exercise as BioZ respiratory-rate measurement or copy its result into Health Connect. / 手錶首頁新入口只開啟原廠練習；它與本 App 的 BioZ 呼吸研究及呼吸速率紀錄不同。
- Raw SpO₂ and temperature / 原始血氧與溫度: The watch now shows OEM-derived preparation tips. Keep the watch against skin, strap snug and wrist still for raw SpO₂; for raw temperature, wear it for at least ten minutes, keep the wrist/watch dry, and avoid charging or recent high-power use. These steps improve the measurement setting; they do not calibrate our raw HAL values. See [the OEM source trace](OEM_SPO2_TEMPERATURE_SOURCE_TRACE.md). / 手錶頁面加入原廠量測前的貼合、靜止及溫度準備提示，仍只保存未校準原始值。
- If no data appears, record the visible state as unavailable, permission denied, uncalibrated, stale, or sync failed. Do not substitute a value from another day or a raw sensor field. / 無資料時記錄實際原因，不用其他日期或原始欄位補值。
