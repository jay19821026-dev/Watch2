## English

**Project title:** AILISA Health Bridge | Android × Wear OS Health Data Research

**Project URL:** https://ailisa.net/portfolio/ailisa-health-bridge

**GitHub:** https://github.com/jay19821026-dev/Watch2

**Description:**

An open-source Android phone and Wear OS health-data project independently developed by Wang You-Jie, compatible with Xiaomi Watch 2 Pro. It uses Wear OS Health Services, the Wearable Data Layer and Health Connect to organize user-authorized heart-rate, activity and sleep records with visible provenance, timing, quality and sync state. Version 4.0 test 20 adds a local source audit informed by static analysis of a user-supplied Mi Fitness 3.53.0i XAPK. It distinguishes denied permission, empty records, read errors and query limits, then checks seven-day record counts, source apps and latest times without displaying or uploading health values. The watch home layout was corrected on the paired device. Phone and watch source, test APKs, bilingual documentation and a dataset–paper–algorithm use map are public. Raw ECG events remain research-only; no OEM ECG unlock or medical-diagnostic claim is made.
