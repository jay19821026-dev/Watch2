## Delivery limitations

- These are QA APKs, not store-ready releases. Both release variants currently use the debug signing configuration and minification is disabled. Do not publish them to Google Play.
- The watch-side lifecycle fix is in the Wear APK but still needs installation and paired-device verification.
- The success target is 100% auditable outcomes for enumerated sensor channels, not a guarantee that every OEM-restricted sensor emits a live physiological value.
- No missing sensor values were fabricated, calibrated, or presented as a medical diagnosis.
