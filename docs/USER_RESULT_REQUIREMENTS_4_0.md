## 開發驗收準則（依原話整理）

1. 結果頁先顯示人能理解的結論、可能原因與下一步；數值、來源及演算法細節放在後面，供需要時查閱。
2. 每個實際量測入口都須有可辨識的完成、重測或未收到資料狀態；錯誤時提供立即重新量測的操作，不能讓使用者只看到破折號或「資料不足」。
3. 優先使用同次量測中可核對來源與時間的原廠／Wear Health Services／Health Connect 生理結果；原始 PPG、ECG、BioZ 與溫度資料需對照已反組譯的原廠輸入路徑，不把不同通道混成一個數值。
4. ECG、PPG 等結果應提供消費型健康參考和可讀的解釋，並在下方以精簡文字說明可能誤差與就醫時機。產品定位為參照型 3C 手錶應用程式。
5. 若某項疾病分類在目前手錶資料上尚無可核對的輸入或驗證證據，應把缺口定位到具體資料路徑或演算法步驟，優先修正與實測；不能用泛稱「資料不足」取代調查，也不能把未執行的分類標成已完成。
