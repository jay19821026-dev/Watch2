# Daily health report / 每日健康報告

作者 / Author: 王宥傑 (Wang You-Jie)

## 繁體中文

手機 App 的「健康趨勢分析」頁現在顯示依手機當地日期產生的每日資料報告。步數與活動熱量取自已授權的 Health Connect 當日 aggregate，並顯示來源；只有前一日與當日來源識別碼相同、兩天都有有效彙總值時，才顯示描述性的昨日差值。靜息心率與 HRV 只顯示量測時間落在當日的最新有效紀錄，並列出來源與時間。沒有資料、未授權、讀取失敗或來源不足時，報告列出缺口，不以 0 或另一日紀錄補值。

目前分析引擎的睡眠時長涵蓋近 30 小時，血氧摘要涵蓋近 7 日；它們不能直接當成單日值，所以每日報告明確標示尚未提供。當日報告不使用原廠 ECG、PPG、BioZ 原始事件生成血氧、疾病分類或醫療建議。頁面文字由手機本機固定規則產生，**沒有呼叫雲端生成式 AI**。使用者可在原有分析區查看更詳細的研究模型；每日報告本身不提供健康總分或正常／異常判定。

## English

The phone app's Health Trend Analysis page now includes a report for the phone's local date. Steps and active calories come from authorized Health Connect daily aggregates and retain source attribution. A descriptive difference from yesterday appears only when both days have valid aggregates and the same nonempty source IDs. Resting heart rate and HRV use only the latest valid measurement whose timestamp falls on the report date, with source and time shown. Missing permissions, records, valid values or source evidence appear as gaps; the report does not substitute zero or another day's value.

The existing sleep-duration input covers a rolling 30 hours and the oxygen summary covers seven days. They are explicitly omitted from the single-day report until per-day queries are implemented. Raw OEM ECG, PPG and BioZ events are not turned into oxygen percentages, disease classifications or treatment advice. Text is generated by deterministic rules on the phone; **no cloud generative AI is called**. The daily report has no overall health score or normal/abnormal verdict.

## Data and method / 資料與方法

| Input / 輸入 | Selection / 選取 | Output / 輸出 |
|---|---|---|
| Health Connect steps and active calories | Local-date aggregate bucket, valid nonnegative value and positive source count | Value, unit, source IDs where available; previous-day difference only with matching IDs |
| Health Connect resting heart rate and HRV | Latest valid record whose measurement timestamp is on the local report date | Value, unit, measurement time and source package |
| Sleep and oxygen | Existing rolling summaries are not same-day queries | Explicit missing-data explanation |

Android's [Health Connect aggregate documentation](https://developer.android.com/health-and-fitness/health-connect/aggregate-data) describes date buckets and deduplication behavior for activity and sleep. Its [data format documentation](https://developer.android.com/health-and-fitness/health-connect/data-format) explains timestamp and zone-offset metadata. The [FDA clinical decision support guidance](https://www.fda.gov/regulatory-information/search-fda-guidance-documents/clinical-decision-support-software) is a regulatory context for keeping health-data organization distinct from patient-specific diagnostic or treatment recommendations; citing it does not make this App FDA-cleared.

The OEM 9.8.348i and 3.59.2i APK comparison informs typed-record timing and the positive SpO₂ gate elsewhere in AILISA; neither OEM APK contains this project's daily prose generator. The report never claims an OEM algorithm was transplanted. See [OEM data-window comparison](OEM_DATA_WINDOW_COMPARISON_4_0.md) and [dataset/paper/algorithm map](ALGORITHM_DATASET_PAPER_MAP.md).
