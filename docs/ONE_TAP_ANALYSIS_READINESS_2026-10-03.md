# 一鍵檢測與分析準備

- 手錶首頁新增「一鍵檢測」，接到現有獨立全掃描頁。仍需使用者於頁面開始掃描與授權，不是背景無限收集。
- 掃描 running 狀態不允許再次掃描；完成、部分成功或失敗後可重試，沿用現有期限與清理路徑。
- 手機分析新增資料準備卡與缺口詳情；既有個別觀察保留，缺少整合模型輸入不虛構分數。
- 修正分析器錯誤描述「模型停用」為「等待配對資料」。
- HRV 讀取已使用 Health Connect HeartRateVariabilityRmssdRecord，原廠 App 顯示 HRV 不保證該記錄已共享到 Health Connect。本輪沒有證據確認原廠 HRV 共享狀態。
- 不將 callback 時間、樣本索引或生成時間冒充量測時間。原廠 HRV 不被宣稱為虛構；缺口重建不能自動解鎖 HRV／生理換算。
- 雙端單元測試、Debug 與 Release 建置通過；新增 UI 尚未實機驗收。未新增 AI 時間戳重建或自動重試排程。
